# x402

PowerChain supports an x402 integration layer for paid APIs and AI/agent
services.

Production policy:

- protocol generation: x402 v2;
- primary Solana payment asset: USDC;
- finalized settlement required;
- HTTPS resources only;
- unique payment references required;
- arbitrary 402 responses are never automatically signed;
- PWRC as a custom x402 payment asset remains experimental/disabled until the
  selected facilitator explicitly supports the exact PWRC mint and scheme.

x402 is an application/payment protocol. It does not modify PWRC's monetary
policy or Token-2022 mint authorities.
