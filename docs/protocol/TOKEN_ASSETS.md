# PWRC Token Assets

Version `1.0.0`.

Repository assets:

```text
public/assets/pwrc.png
public/assets/wpwrc.png
```

When hosted by a web application using `public/` as the static root, these are
available as:

```text
/assets/pwrc.png
/assets/wpwrc.png
```

```text

Public metadata JSON:  https://token.powerchain.energy/metadata/metadata.json
PWRC public image:     https://token.powerchain.energy/assets/tokens/pwrc-logo.png
wPWRC public image:    https://token.powerchain.energy/assets/tokens/wpwrc-logo.png
```

PowerChain product links:

```text
Website: https://powerchain.energy
Bridge:  https://bridge.powerchain.energy
App:     https://app.powerchain.energy
Docs:    https://docs.powerchain.energy
```

The canonical PWRC metadata describes the asset as a Token-2022 utility and
governance token for tokenized renewables and real-world assets. The metadata
remains versioned at `1.0.0`.
